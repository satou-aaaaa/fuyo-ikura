# 扶養控除いくら？（fuyo-ikura）

生計を一にする家族の場面（高校生・大学生の子・70歳以上の親・同居・老人ホーム・事業専従者 など）を読んで、扶養控除・特定親族特別控除の額を当てる1日5問の学習ゲーム。正解したら「どの計算？」（一般の扶養親族・特定扶養親族・老人扶養親族・特定親族特別控除・受けられない）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/fuyo-ikura/>

- 答えは、国税庁タックスアンサーと用語集の表（12月31日に16歳以上・合計所得金額62万円以下で扶養控除38万円。19歳以上23歳未満は63万円、70歳以上は48万円、同居の親・祖父母は58万円。19歳以上23歳未満で62万円超123万円以下は特定親族特別控除）から出しています（［令和8年4月1日現在法令等］と、令和8年分から使う改正の注記。2026-11-17 に読みました）。
  - No.1180 扶養控除 <https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1180.htm>
  - No.1177 特定親族特別控除 <https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1177.htm>
  - 用語集（扶養親族・特定扶養親族・老人扶養親族・同居老親等） <https://www.nta.go.jp/taxes/shiraberu/taxanswer/yogo/senmon.htm>
- 金額は令和8年分の決まりです（所得の境目は62万円）。場面の家族はどれも生計を一にする居住者です。税額・障害者控除・非居住者・給与収入から所得への計算・申告の手続きは出しません。人と金額はつくりものです。
- このゲームは扶養控除のしくみを知る練習です。税の相談の代わりではありません。実際の控除の額は、国税庁の資料や税務署で確かめてください。
